Cast Off

A free Mac menu bar app for unhooking drives that won’t eject.

Install Cast Off

git clone https://github.com/bslisher/cast-off.git && cd cast-off && ./build.sh

Paste that in a macOS Terminal prompt.

Requires macOS 13 or later and Xcode or its Command Line Tools.

  • Finds the snag

    Shows what’s keeping your drive busy.

  • Catch and release

    Asks only indexers to quit, and macOS brings them back. Your apps are left alone.

  • Never snaps the line

    It won’t force-eject. If the drive isn’t free yet, it can wait.
